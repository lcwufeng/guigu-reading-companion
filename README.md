# 龟龟伴读

面向小学生的电子宠物学习陪伴应用。用户可以在像素风家园里照顾小乌龟，并通过读书、聊天和旅行留下成长记录。

## V1 功能

- 四项宠物状态：饱腹、干净、有趣、心情
- 喂果子、游泳清洁、四处捉迷藏、睡觉
- 三本内置短篇、阅读提问、语音或文字回答、阅读总结
- 日常学习聊天和儿童友好的引导回复
- 四个旅行地点、限时旅行、照片与知识卡奖励
- 旅行手账、阅读记录、小背包
- 宠物改名和本机进度保存

## 本地运行

```bash
npm install
npm run dev
```

打开开发服务显示的本地地址即可体验。

## 验证

npm test
